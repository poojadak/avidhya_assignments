# /ship — Full Pipeline: Review → Test → Commit → PR

This runs the complete shipping pipeline from staged changes to an open pull request.

## What this does

Runs these four steps in order. If any step fails, it stops and tells you what to fix.

---

### Step 1: /review

```
Run: git diff --staged
```

Check all staged changes against CLAUDE.md conventions. If there are CRITICAL issues, stop here and list them. Don't proceed until they're fixed.

---

### Step 2: /test-gen

```
Run: git diff --name-only --staged
Run: npm test -- --coverage
```

Generate any missing tests for changed files, then run the full test suite. If tests fail, stop and show the failure output. Don't commit broken code.

---

### Step 3: /commit

```
Run: git diff --staged
```

Generate a conventional commit message from the diff. Show it to the user and confirm before committing.

```
Run: git commit -m "<generated message>"
```

---

### Step 4: Create PR

```
Run: git push origin HEAD
Run: gh pr create --title "<commit message>" --body "<auto-generated description>"
```

The PR body should include:
- What changed (1-2 sentences)
- How to test it
- Any notes for the reviewer

---

## Output format

```
## /ship Pipeline

[✓] Step 1: Review — PASSED
[✓] Step 2: Tests — PASSED (coverage: X%)
[✓] Step 3: Commit — "feat(auth): add token refresh endpoint"
[✓] Step 4: PR — https://github.com/org/repo/pull/42

Done! Your changes are up for review.
```

If anything fails:
```
[✓] Step 1: Review — PASSED
[✗] Step 2: Tests — FAILED

3 tests failed. Fix these before shipping:
- auth.test.js: "should refresh token" — TypeError: ...
```
